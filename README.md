# waveshare-ePaper7.3
AI gen image for waveshare 7.3'' ePaper display

This project uses a [Waveshare 7.3-inch e-Paper HAT (4-color)](https://www.waveshare.com/wiki/7.3inch_e-Paper_HAT_(G)), but any 7.3'' display with Raspberry HAT can be installed, including full-color screens.

In my implementation, a Raspberry Pi Zero 2W is used, running a test script written in MicroPython. The script downloads a new sci-fi-themed generated by Gemini AI image for the frame once a day. The code is fully customizable to suit your needs.
